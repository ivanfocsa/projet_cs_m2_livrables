# Checklist onboarding d'un site client

| Controle | Statut |
|---|---|
| Code site cree | A faire |
| Nom du responsable local identifie | A faire |
| Liste des postes collectee | A faire |
| Liste des serveurs collectee | A faire |
| Equipement firewall identifie | A faire |
| Applications metier identifiees | A faire |

| Controle | Statut |

| Agent installe sur les serveurs | A faire |
| Syslog firewall configure | A faire |
| Logs applicatifs declares | A faire |
| Logs messagerie declares | A faire |
